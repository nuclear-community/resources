# 📖 resources

**A curated library of the best nuclear science & engineering resources — free first, annotated, and maintained by the community.**

Part of the [Nuclear Science & Engineering Community](https://github.com/nuclear-community). Companion to our learning path, [nuclear-101](https://github.com/nuclear-community/nuclear-101).

## The library

| File | What's inside |
| --- | --- |

## How to use this library

- **Tags.** Every entry is tagged with a level — 🟢 beginner · 🟡 intermediate · 🔴 advanced — and an access note: **free**, **free (registration)**, **free (academic)**, or **paid**.
- **Start free.** You can get from zero to a serious working knowledge without spending anything. The paid textbooks are for going deeper.
- **Pair with [nuclear-101](https://github.com/nuclear-community/nuclear-101).** Each learning module points to a subset of these resources in context.

## Inclusion criteria

1. **Accuracy and authority** — reputable authors, institutions, or publishers
2. **Free first** — paid resources are included when they're the standard, and always marked
3. **English** (the community's working language)
4. **Working links** — dead links get fixed or removed

## Contribute

Found something excellent that's missing? A broken link? [Open an issue](https://github.com/nuclear-community/resources/issues) or send a pull request — see the [contributing guide](https://github.com/nuclear-community/.github/blob/main/CONTRIBUTING.md). When suggesting a resource, tell us *who it's for* and *why it's good*, not just the link.
